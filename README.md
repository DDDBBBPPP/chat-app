# Chat App

A messaging interface built with **Angular and Ionic**, designed to provide a mobile-friendly chat experience.

**[Live Demo](https://dddbbbppp.github.io/chat-app/)** · **[Source Code](https://github.com/DDDBBBPPP/chat-app)**

## Overview

Chat App lets users explore a messaging interface in the browser, including login and registration screens, a conversation list, and individual chats.

This is a **frontend demo** powered by mock data. It does not include a messaging backend or real authentication, and messages are not exchanged between actual users.

## Tech Stack

- Angular 20
- Ionic 8
- TypeScript
- Capacitor

## Live Demo

Explore the application on [GitHub Pages](https://dddbbbppp.github.io/chat-app/).

The demo starts on the login screen. Accounts and conversations are simulated, so signing up does not create a real account or connect you to other users.

## Run Locally

**Requirements:** Node.js and npm.

Clone the repository and install its dependencies:

```bash
git clone https://github.com/DDDBBBPPP/chat-app.git
cd chat-app
npm ci
```

Start the development server:

```bash
npm start
```

Open the local URL shown in your terminal.

To create a production build:

```bash
npm run build -- --configuration production
```

## Project Scope

This project focuses on the interface, navigation, and user experience of a chat application. It does not include a backend, shared message storage, or real-time communication between users.
